## Executive Summary

NeuroFaith addresses a critical gap in Large Language Model (LLM) explainability: natural language self-explanations generated by LLMs may sound plausible but often fail to reflect the model's actual internal reasoning process. By aligning LLM internal representations with their textual self-explanations, NeuroFaith provides a principled framework for measuring faithfulness—ensuring that explanations truly represent what the model "thinks" when making predictions. This work bridges mechanistic interpretability and human-centered explainability, enabling both the detection and improvement of LLM explanation quality.

## Problem Statement

### The Faithfulness Gap in LLM Explanations

Large Language Models have become ubiquitous for decision-making across critical domains—medicine, law, finance, and governance. Users increasingly rely on LLM-generated explanations to understand and trust model predictions. However, a troubling phenomenon has emerged:

1. **Plausibility vs. Faithfulness**: LLMs can generate explanations that *sound* coherent and reasonable but do not actually represent the model's reasoning process. This is the distinction between *plausible* explanations (which read well) and *faithful* explanations (which accurately reflect internal computation).

2. **Existing Evaluation Methods Limitations**:
   - Behavioral tests (e.g., counterfactual reasoning) only measure whether changing the explanation leads to changed predictions
   - Computational block analysis (e.g., ablation studies) is model-specific and computationally expensive
   - Neither method examines whether the *semantic content* of explanations aligns with what the model's internal representations actually encode

3. **Real-World Consequences**:
   - Users may trust explanations that mask the true decision process
   - Accountability and transparency goals are undermined
   - Regulatory compliance (e.g., GDPR's "right to explanation") is compromised if explanations are unfaithful
   - In high-stakes domains (medicine, law), unfaithful explanations can lead to poor decision-making

### Why Existing Approaches Fall Short

Traditional post-hoc explanation methods (LIME, SHAP) were designed for classical ML models with fixed, interpretable parameters. LLMs present new challenges:

- **Scale**: Modern LLMs contain billions of parameters; examining all computational paths is infeasible
- **Stochasticity**: Different runs can produce different explanations for the same input
- **Complexity**: How can we verify that a natural language explanation actually captures the high-dimensional latent reasoning in attention heads, neurons, and circuit connections?

NeuroFaith bridges this gap by using mechanistic interpretability techniques—specifically, decoding and probing—to validate whether concepts emphasized in LLM self-explanations have genuine mechanistic effects on the model's output.

## Core Concepts & Theory

### 1. Mechanistic Interpretability and Neural Probes

**Mechanistic interpretability** asks: "How does the model actually compute its output at the level of individual neural components?"

Key concepts:

- **Hidden States**: The internal activations of neural network layers. For LLMs, these are high-dimensional vectors (e.g., 4096-dimensional for many models) that encode information processed up to that token position.

- **Neural Probes (Decoders)**: Simple classifiers (often linear) trained to predict semantic information from hidden states. If a probe can accurately decode a concept (e.g., "the subject noun") from a hidden state, we infer that the model encodes that concept at that layer and position.

- **Circuit Discovery**: The idea that neural networks decompose into functionally meaningful circuits—subnetworks that perform specific computations. For example, one circuit might handle subject-verb agreement, another might handle negation.

### 2. Faithfulness Definition

In NeuroFaith, **faithfulness** is defined as a multi-dimensional property:

A self-explanation is faithful if:

1. **Concept Extraction**: The explanation can be decomposed into interpretable concepts (e.g., "the model noticed X because of feature Y")

2. **Mechanistic Validity**: Each concept in the explanation has a measurable, causal effect on the model's prediction
   - If the explanation says "concept C influenced the prediction," then perturbing C in the model's internals should change the output
   - This is verified using intervention techniques (e.g., causal tracing, attention pattern manipulation)

3. **Representational Alignment**: The concepts emphasized in the explanation align with what the model's hidden representations actually encode
   - If a concept appears important in the explanation, it should be decodable from hidden states
   - The alignment should be consistent across layers and positions

### 3. Linear Structure in Representation Space

A key insight from NeuroFaith is that **faithfulness exhibits linear structure** in representation space:

- For 2-hop reasoning and classification tasks, faithful vs. unfaithful explanations can be distinguished using linear classifiers trained on hidden representations
- This suggests that the distinction between faithful and unfaithful explanations is "embeddable" in the model's representation space
- This linear structure enables both efficient detection and intervention-based improvement

### 4. Steering and Improvement

Once a linear faithfulness direction is identified, it can be used to:

- **Detect**: Quickly identify whether an explanation will be unfaithful before generation
- **Steer**: Guide the model toward generating more faithful explanations through activation steering (perturbing hidden states during generation)

## Main Ideas & Key Contributions

### 1. The NeuroFaith Framework

NeuroFaith is a flexible, modular framework with three key components:

**Location**: Where in the model's computation should we look?
- Specific layers and token positions where concepts are encoded
- Different concepts may be encoded at different depths (e.g., low-level syntactic features in shallow layers, semantic concepts in deeper layers)

**Circuit**: Which neural connections and transformations implement the computation?
- Attention heads that gather relevant information
- Feed-forward components that integrate information
- Skip connections that bypass certain computations

**Interpreter**: How do we decode concepts from neural representations?
- Linear probes for efficiency
- Nonlinear interpretability methods for more complex concepts
- Multi-hop reasoning chains that trace concepts through layers

### 2. Core Technical Process

The NeuroFaith evaluation pipeline:

```
1. Generate explanation from LLM
   ↓
2. Parse explanation into propositions and concepts
   ↓
3. For each concept in the explanation:
   a. Train neural probes to detect concept in hidden states
   b. Use causal intervention (attention manipulation, activation perturbation) to test if concept causally affects output
   c. Measure fidelity: does perturbing the concept change the prediction in the way the explanation predicts?
   ↓
4. Aggregate: compute overall faithfulness score
   ↓
5. Detect linear structure: train linear classifier on representation space to distinguish faithful vs. unfaithful explanations
   ↓
6. Steer: use linear direction to improve faithfulness through activation steering
```

### 3. Connection to Mechanistic Interpretability

NeuroFaith advances mechanistic interpretability by:

- **Bridging to NLP**: Previous mechanistic interpretability work focused on vision and simple algorithmic tasks; NeuroFaith brings these techniques to language understanding
- **Semantic Grounding**: Rather than just finding circuits, NeuroFaith grounds circuits in human-readable explanations
- **Practical Validation**: It provides a concrete evaluation method for whether mechanistic understanding actually translates to better explanations

### 4. Novelty and Contributions

**Specific Innovations**:

1. **Faithfulness Evaluation Without Behavioral Access**: Unlike existing methods, NeuroFaith doesn't require controlling model inputs or observing behavioral changes. It evaluates explanations purely from representation patterns.

2. **Versatile Framework**: Works across different tasks (reasoning, classification), model sizes, and explanation types without task-specific engineering.

3. **Causal Mechanistic Testing**: Combines probing (observational inference) with intervention (causal testing) to go beyond correlation.

4. **Steering for Improvement**: Unlike most explanation evaluation methods (which only diagnose), NeuroFaith enables improvement through steering.

5. **Linear Structure Discovery**: Identifying linear faithfulness structure opens the door to fast, scalable detection and improvement methods.

## Methodology & Implementation

### Experimental Setup

**Models Tested**:
- GPT-style language models at various scales
- Models fine-tuned for reasoning and classification tasks

**Tasks**:

1. **2-Hop Reasoning**: Models reason over facts ("Alice is smart," "Smart people win") to answer questions ("Does Alice win?")
   - Explanations should identify the two-step reasoning chain
   - Faithfulness requires that removing either step breaks the prediction

2. **Classification**: Sentiment analysis, relation classification, etc.
   - Explanations identify key features or evidence for classification
   - Faithfulness requires that these features causally influence the prediction

**Datasets**:
- Synthetic reasoning datasets (controlled for ground truth reasoning chains)
- Standard NLP classification benchmarks (e.g., sentiment analysis datasets)
- Evaluation sets designed to test edge cases and robustness

### Evaluation Metrics

**Faithfulness Metrics**:

1. **Probe Accuracy**: Can linear/nonlinear probes accurately decode concepts from hidden states?
   - Higher accuracy → concept is well-represented internally
   - Ranges from baseline (random) to ceiling (perfect prediction)

2. **Intervention Fidelity** [Exact figures unavailable — see full paper]:
   - When a concept is perturbed in hidden states, does the model's behavior align with the explanation's prediction?
   - Example: If explanation says "X made the model predict Y," does removing/flipping X cause the model to change its prediction or confidence?

3. **Alignment Score**: 
   - Measures whether the set of concepts identified by probes overlaps with the concepts mentioned in the explanation
   - Ranges from 0 (no overlap) to 1 (perfect alignment)

4. **Linear Faithfulness Classifier Accuracy** [Exact figures unavailable — see full paper]:
   - Trains a linear classifier to distinguish faithful vs. unfaithful explanations from hidden representations
   - High accuracy indicates faithfulness has a clear representational signature

### Key Findings

**1. Faithfulness Structure is Linear**:
- For tested tasks, faithfulness exhibits strong linear structure in representation space
- A simple linear classifier can often distinguish faithful from unfaithful explanations with high accuracy
- This is a surprising and non-obvious finding (many phenomena in deep learning are highly nonlinear)

**2. Emerging Similarity with Safety Behaviors**:
- The learned faithfulness direction shows emergent similarity with other established safety behaviors (e.g., honesty, harmlessness)
- This suggests faithfulness may be a more general property of model behavior

**3. Steering Improves Faithfulness**:
- Perturbing model activations along the learned faithfulness direction improves explanation quality
- Improvement is consistent and measurable across different tasks and model scales

**4. Limitations and Challenges**:
- Faithfulness varies significantly by task complexity
- Longer, multi-hop reasoning chains are harder to verify than simple classifications
- Computational cost increases with model size (probing and intervention become more expensive)

## Practical Applications & Real-World Use Cases

### 1. Healthcare and Medical AI

**Application**: AI systems diagnosing diseases from patient data (imaging, lab results, symptoms)

**Challenge**: Doctors need to understand why the AI recommends a diagnosis. If the AI says "I detected pneumonia from the chest X-ray because of opacities in the lower lobes," the radiologist must verify this is truly what influenced the prediction.

**NeuroFaith Solution**:
- Validate that explanations about specific image regions actually correspond to features the model mechanistically uses
- Ensure explanations aren't just plausible-sounding post-hoc rationalizations
- Enable steering to improve explanation quality if initial explanations are found to be unfaithful

**Regulatory Implication**: FDA guidance requires AI systems to provide interpretable decision-making. Certified faithfulness strengthens compliance claims.

### 2. Legal and Contract Analysis

**Application**: LLMs analyzing legal documents, contracts, or court cases

**Challenge**: Lawyers need to trust explanations for contract terms the AI flags as risky. Hallucinated or unfaithful explanations could lead to poor legal decisions.

**NeuroFaith Solution**:
- Verify that explanations citing specific contract clauses actually correspond to decision-influencing computations
- Distinguish between genuine legal reasoning and spurious pattern-matching
- Improve explanation quality through steering for critical decisions

**Regulatory Implication**: GDPR's "right to explanation" requirement becomes meaningful only if explanations are faithful. NeuroFaith provides a technical foundation for compliance.

### 3. Financial Decision-Making

**Application**: LLMs used for credit decisions, fraud detection, or investment recommendations

**Challenge**: Regulators (e.g., Federal Reserve) increasingly require explainability in financial AI. Unfaithful explanations undermine compliance.

**NeuroFaith Solution**:
- Audit explanation faithfulness as part of model validation before deployment
- Detect and correct unfaithful explanations that could mislead regulators or users
- Provide evidence of careful model behavior verification

### 4. Content Moderation at Scale

**Application**: LLMs determining which user content violates platform policies

**Challenge**: Moderators need to understand why content was flagged. Unfaithful explanations erode user trust and create appeals challenges.

**NeuroFaith Solution**:
- Validate that moderation explanations reflect actual policy reasoning
- Improve explanations for borderline cases where the model's decision boundary is ambiguous
- Enable auditing for bias (e.g., explanations that appear fair but mask discriminatory computation)

### 5. Educational AI

**Application**: Tutoring systems explaining math, science, or writing

**Challenge**: If explanations are unfaithful, students may learn incorrect reasoning. Faithful explanations are essential for educational value.

**NeuroFaith Solution**:
- Ensure pedagogical explanations align with the model's actual computational process
- Detect when explanations oversimplify or misrepresent reasoning
- Steer toward explanations that are both faithful and pedagogically effective

## Insights & Implications

### 1. Theoretical Implications

**Representation Learning Insight**: The discovery of linear faithfulness structure suggests that semantic meaning (like "faithfulness") may be preserved in a relatively simple, linear manner in high-dimensional representation space. This aligns with recent work on superposition and has implications for:
- Understanding how language models generalize
- Designing more interpretable model architectures
- Scaling mechanistic interpretability to larger models

**Causal Understanding in NLP**: NeuroFaith demonstrates that causal reasoning (intervention, not just correlation) is essential for evaluating LLM explanations. This strengthens the case for causal inference methods in NLP, moving beyond observational techniques.

### 2. Advancing Trustworthy AI

**From Plausibility to Accountability**:
- Many existing explanation methods optimize for plausibility (making explanations sound good)
- NeuroFaith emphasizes faithfulness (making explanations truthful)
- This shift is crucial for building genuinely trustworthy AI systems

**Regulatory Compliance**:
- Regulatory bodies (EU AI Act, FDA, SEC) are increasingly requiring explainability
- NeuroFaith provides technical evidence that explanations are faithful, strengthening compliance arguments
- Enables organizations to audit and improve explanation quality before deployment

### 3. Limitations and Open Questions

**Computational Scalability**:
- Probing and intervention techniques can be expensive for very large models (100B+ parameters)
- Future work needed for efficient faithfulness evaluation at scale

**Concept Representation**:
- How should we represent complex, multi-faceted concepts (e.g., "economic impact") in mechanistic terms?
- Currently focuses on relatively discrete, atomic concepts
- Future work: compositional faithfulness evaluation

**Generalization**:
- Does faithfulness structure discovered in one task/domain transfer to others?
- Preliminary results suggest some transfer, but more work needed

**Adversarial Robustness**:
- Can models be trained to appear faithful (in representation space) while actually reasoning differently?
- Analogous to adversarial examples but in explanation space
- Need for robustness evaluation of faithfulness metrics themselves

### 4. Broader XAI Research Directions

**From Post-Hoc Explanations to Interpretable Models**:
- NeuroFaith validates that mechanistic properties (linear structure, causal circuits) underlie explanations
- This supports the design of inherently interpretable models that encode explanations in their representations

**Human-AI Collaboration**:
- Faithful explanations enable better human-AI collaboration in high-stakes domains
- Future work: co-design of explanations to be both faithful and pedagogically effective for different user populations (experts vs. lay users)

**Explanation Feedback Loops**:
- NeuroFaith's steering capability enables interactive improvement of explanations
- Future: systems that learn from human feedback to refine faithfulness over time

## Summary

NeuroFaith represents a significant step toward trustworthy LLMs by directly addressing the gap between plausible and faithful explanations. By combining mechanistic interpretability techniques with rigorous evaluation, it provides both a diagnostic tool (detecting unfaithful explanations) and an intervention method (steering toward better explanations). For practitioners deploying LLMs in high-stakes domains, NeuroFaith offers essential validation that user-facing explanations actually reflect model reasoning. For researchers, it opens new directions in understanding how neural networks represent semantic meaning and causal relationships.

The discovery of linear faithfulness structure is particularly promising for scaling to larger models and enables future work on efficient, automated explanation quality verification and improvement.
