**ArXiv ID**: [2506.19850](https://arxiv.org/abs/2506.19850)

**Published**: June 24, 2025  
**Venue**: ICLR 2026  
**Field**: Robotics, Computer Vision, Multimodal Learning

---

## Executive Summary

UniVLA presents a unified autoregressive framework that represents vision, language, and action signals as a single stream of discrete tokens, enabling a robot policy model to learn jointly from large-scale internet video and task demonstrations. By treating all modalities symmetrically and incorporating world modeling—predicting future visual states from current observations and actions—UniVLA captures the causal dynamics of the physical world and transfers this understanding to downstream manipulation tasks. The approach achieves state-of-the-art results across CALVIN, LIBERO, and SimplerEnv-Bridge benchmarks, with particularly dramatic gains on long-horizon tasks, and has been accepted at ICLR 2026.

---

## Problem Statement

### The Gap in Prior Vision-Language-Action Models

Existing Vision-Language-Action (VLA) models—such as OpenVLA, π₀ (pi-zero), and RT-2—share a common architectural pattern: they bolt a pre-trained Vision-Language Model (VLM) onto a policy head. In this paradigm:

1. **A separate vision encoder** extracts image features (e.g., a CLIP or SigLIP encoder).
2. **A language model backbone** processes combined visual and text tokens.
3. **An action head** (a simple MLP or diffusion head) maps the fused representation to robot commands.

This design has two significant limitations:

- **Asymmetric modality treatment**: Vision and language are fused via a pre-trained encoder, but actions are generated by an entirely separate pathway. This prevents the model from reasoning about future visual states *in the same representational space* as the policy.
- **Wasted temporal signal**: Robotic tasks unfold over time. Video data carries rich causal information—pressing a button causes a light to turn on; pushing an object causes it to move. Prior models treat each frame largely independently and do not explicitly model how actions cause visual changes.

Consequently, prior VLAs struggle with **long-horizon tasks** that require planning over many steps and anticipating future states. The SimplerEnv-Bridge benchmark highlighted this: the previous state-of-the-art sat at just 42.7% average success rate.

### The Research Question

> *Can a single autoregressive model, trained on discrete token sequences spanning vision, language, and action, learn the causal dynamics of the world well enough to become a superior robot policy?*

## Core Concepts & Theory

### 1. Discrete Tokenization of All Modalities

UniVLA's central architectural insight is to convert every modality into a stream of discrete integer tokens, so that an autoregressive Transformer can model all modalities uniformly.

#### Image Tokenization via Vector Quantization (VQ)

Images are encoded into discrete tokens using a **Vector-Quantized (VQ) encoder**—a component popularized by VQ-VAE. The process:

```
Image (H×W×3)
     ↓  CNN/ViT Encoder
Continuous feature map (h×w×d)
     ↓  Nearest-neighbor lookup in codebook C ∈ ℝ^{K×d}
Discrete token grid (h×w), each entry ∈ {0, 1, ..., K-1}
     ↓  Flatten
Sequence of image tokens [i₁, i₂, ..., i_{h·w}]
```

The codebook is trained jointly with the encoder via a commitment loss, ensuring that the discrete codes faithfully reconstruct the original image.

#### Action Tokenization via Discrete Cosine Transform (DCT)

Robot actions (e.g., joint angles, end-effector poses) are **continuous, multi-dimensional, and temporally smooth**. Directly quantizing raw action values wastes representational capacity on high-frequency noise. UniVLA instead applies the **Discrete Cosine Transform (DCT)** before quantization:

```
Action sequence A ∈ ℝ^{T×D}  (T timesteps, D DoF)
     ↓  DCT along time axis
Frequency coefficients Â ∈ ℝ^{T×D}
     ↓  Keep low-frequency components (compression)
     ↓  Scalar quantization
Discrete action tokens [a₁, a₂, ..., a_M]
```

The intuition: robot motions are smooth curves in joint space. The DCT concentrates energy in low-frequency components, so a small number of DCT coefficients can faithfully represent a trajectory. This makes quantization more efficient and reduces the token budget for actions.

#### Language Tokenization

Task instructions use standard BPE tokenization, identical to how language models process text.

### 2. Unified Autoregressive Sequence

All tokenized modalities are **interleaved** into a single causal sequence:

```
[lang_1, ..., lang_L, img_1^t1, ..., img_N^t1, act_1^t1, ..., act_M^t1,
 img_1^t2, ..., img_N^t2, act_1^t2, ..., act_M^t2, ...]
```

A decoder-only Transformer models `P(token_i | token_1, ..., token_{i-1})` using the next-token prediction objective. This causal structure naturally encodes **temporal causality**: the model must learn that actions at time `t` cause the visual observations at time `t+1`.

### 3. World Modeling as a Pre-Training Objective

To exploit large-scale internet video (which contains no action labels), UniVLA introduces a **world modeling objective**:

> Given a sequence of image tokens and (optionally) action tokens, predict the *next* image token sequence.

In video data without robot actions, the model learns to predict future visual frames—essentially learning a **video prediction model**. This forces the model to internalize how the world changes over time. When action tokens are available (from robot demonstrations), the world modeling objective becomes conditioned on actions, teaching the model the causal relationship between actions and outcomes.

This two-phase approach:
1. **Pre-training on internet video**: learn general visual dynamics without any robot data.
2. **Post-training / fine-tuning on robot demonstrations**: fine-tune the world model with actual action labels, then use the resulting representations for policy learning.

## Main Ideas & Key Contributions

### Contribution 1: Truly Unified Multimodal Representation

Previous VLAs are *not* truly unified—they use separate pathways for different modalities. UniVLA is the first model to treat vision, language, *and* action as equivalent citizens in a single token vocabulary. This enables:
- **Multimodal generation**: the model can output image tokens (for world modeling) or action tokens (for policy), with no architectural switching.
- **Cross-modal reasoning**: the model can predict how actions will change the visual state, enabling implicit planning.

### Contribution 2: DCT Action Encoding

The choice of DCT for action representation is non-trivial. Compared to direct quantization:
- **Higher fidelity** with fewer tokens (energy compaction)
- **Smoother trajectories** that avoid jerky motions from quantization artifacts
- **Better generalization** because low-frequency representations are more transferable across tasks

### Contribution 3: World Modeling as a Bridge

World modeling acts as a **scalable bridge** between abundant internet video and scarce robot demonstrations. The model's policy capabilities scale with the amount of video data used for world modeling—a highly practical finding, since internet video is far more plentiful than labeled robot trajectories.

### Contribution 4: State-of-the-Art Across Multiple Benchmarks

UniVLA does not trade off one benchmark for another; it achieves SOTA improvements across all evaluated benchmarks simultaneously, suggesting the approach captures fundamental properties of robotic manipulation rather than overfitting to specific evaluation protocols.

## Methodology & Implementation

### Training Pipeline

```
Stage 1: Large-scale video pre-training
├── Dataset: Open-X Embodiment + internet video datasets
├── Objective: Next-token prediction on [image, action] sequences
│   └── World modeling: predict future image tokens
└── Result: Model learns visual dynamics and causality

Stage 2: Policy post-training  
├── Dataset: Task-specific robot demonstrations
├── Objective: Next-token prediction on [instruction, image, action] sequences
└── Result: Task-conditioned manipulation policy
```

### Experimental Setup

| Benchmark | Description | Metric |
|-----------|-------------|--------|
| **CALVIN** | 4-task tabletop manipulation, 1000 episodes | Avg. tasks completed (0–4) |
| **LIBERO** | 5 suites: Spatial, Object, Goal, Long, 10 | Avg. success rate (%) |
| **SimplerEnv-Bridge** | Sim2Real evaluation using real robot data | Avg. success rate (%) |
| **ALOHA** | Real-world bimanual manipulation | Task success rate |

### Key Results

| Benchmark | Previous SOTA | UniVLA | Improvement |
|-----------|--------------|--------|-------------|
| LIBERO (overall) | 85.5% (π₀-FAST) | **95.5%** | +10.0% |
| LIBERO-Long | 69.0% | **94.0%** | +25.0% |
| SimplerEnv-Bridge | 42.7% | **69.8%** | +27.1% |

The improvement on LIBERO-Long (+25%) is particularly striking, confirming the hypothesis that world modeling specifically helps long-horizon task performance.

### Computational Requirements

- **Pre-training**: Requires significant compute (large-scale video + Open-X data)
- **Fine-tuning**: Standard GPU cluster; the authors report fine-tuning on demonstration datasets is feasible on academic hardware
- **Inference**: Single GPU; the discrete tokenization approach is computationally efficient compared to diffusion-based action heads

## Practical Applications & Real-World Use Cases

### 1. Robotic Manipulation

The primary application domain. UniVLA's strong performance on LIBERO-Long suggests it can handle realistic household or industrial tasks that require sequential multi-step execution:
- Assembling components in order
- Preparing a meal (pick, place, pour, stir)
- Sorting and organizing objects

### 2. Autonomous Driving

The paper demonstrates applicability to autonomous driving, where the same formulation—predict action tokens given visual observations and instructions—directly applies. The world modeling objective, trained on driving videos, enables the model to anticipate traffic scenarios.

### 3. Humanoid Robot Control

The ALOHA bimanual real-world results show that UniVLA scales to complex dexterous manipulation tasks, suggesting applicability to humanoid robots performing fine-grained tasks.

### 4. Robot Foundation Models

From a research perspective, UniVLA is a step toward a **generalist robot foundation model**: a single checkpoint pre-trained on diverse data that can be efficiently fine-tuned to any manipulation task.

### Implementation Challenges

- **Codebook quality**: The quality of discrete image tokens depends heavily on VQ encoder training; poor codebooks degrade image reconstruction fidelity.
- **Action precision**: DCT quantization introduces a reconstruction error; for very precise manipulation tasks, higher-frequency DCT components may need to be retained.
- **Data diversity**: World modeling benefits scale with data diversity; curating high-quality internet video datasets is non-trivial.

## Insights & Implications

### Broader Implications for Embodied AI

1. **Modality symmetry matters**: Treating actions as just another token type—rather than a special output—enables richer cross-modal reasoning and better policy learning.

2. **Video is an untapped resource**: The robotics community has historically relied on costly teleoperated demonstrations. UniVLA's world modeling approach shows that cheap, abundant internet video can serve as a powerful pre-training source.

3. **DCT as an action representation**: The success of DCT encoding challenges the common practice of directly quantizing raw action values and may inspire similar frequency-domain approaches in other continuous control settings.

### Limitations and Open Questions

- **Tokenization fidelity ceiling**: Discrete tokenization of images and actions introduces irreversible information loss. Future work might explore adaptive codebook sizes or continuous latent representations.
- **Long-context scalability**: Modeling long action sequences as interleaved tokens requires long context windows; inference becomes quadratically expensive with sequence length.
- **Sim-to-Real gap**: While SimplerEnv-Bridge is a sim2real benchmark, real-world performance gaps remain a concern for deployment.
- **What causal structures does world modeling actually learn?** Interpretability studies of the world model's internal representations remain an open research direction.

### Impact on the Field

UniVLA represents a paradigm shift from the "VLM backbone + action head" recipe toward truly unified multimodal robot policies. Its acceptance at ICLR 2026 and strong empirical results are likely to accelerate adoption of discrete tokenization and world modeling in next-generation robot learning systems.

### Quick Start

```python
# Load pre-trained UniVLA checkpoint
from univla import UniVLAPolicy

policy = UniVLAPolicy.from_pretrained("baaivision/univla-base")

# Encode observation and language instruction
obs = policy.encode_image(image)          # VQ tokenize
instruction = policy.encode_text("pick up the cup")

# Generate action tokens autoregressively
action_tokens = policy.generate(obs, instruction)
actions = policy.decode_actions(action_tokens)  # DCT inverse
```

## Related Work & Context

### Foundation Papers This Builds Upon

| Paper | Contribution | Relation to UniVLA |
|-------|-------------|-------------------|
| **RT-2** (Brohan et al., 2023) | VLM for robot policy via fine-tuning | UniVLA replaces the separate action head with unified token prediction |
| **OpenVLA** (Kim et al., 2024) | Open-source VLA with tokenized actions | UniVLA extends to images-as-tokens and world modeling |
| **π₀ / pi-zero** (Black et al., 2024) | Flow matching VLA, SOTA before UniVLA | UniVLA surpasses π₀-FAST on LIBERO by +10% |
| **VQ-VAE** (van den Oord et al., 2017) | Discrete image representation via VQ | UniVLA's image tokenizer |
| **VideoGPT** (Yan et al., 2021) | Autoregressive video generation with VQ | Inspiration for video world modeling |
| **Genie** (Bruce et al., 2024) | Latent action world model from video | Similar world modeling objective |

### Contemporary Related Work

- **CoWVLA** (CVPR 2026): Chain-of-World VLA, also explores world model thinking in latent motion space—a complementary approach.
- **RynnVLA-002**: Another unified VLA model building on similar principles.
- **Open-X Embodiment** dataset continues to grow, providing more training data for world modeling.

### Where This Research May Lead

1. **Scaling laws for robot world models**: As more video data becomes available, do robot policies improve predictably?
2. **Hierarchical planning**: Could world models be used for explicit look-ahead planning (similar to AlphaZero's MCTS)?
3. **Cross-embodiment transfer**: A world model trained on diverse embodiments may enable zero-shot transfer to new robot morphologies.
4. **Real-time inference optimization**: Quantized discrete representations may be compressible for edge deployment on robot hardware.
